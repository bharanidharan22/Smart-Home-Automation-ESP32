# Smart Home Automation System using ESP32

## Project Overview

This project enables wireless control of home appliances using an ESP32 microcontroller and a 4-channel relay module through Arduino IoT Cloud.

## Features

* Control lights and appliances remotely
* Real-time monitoring using Arduino IoT Cloud
* Wi-Fi based automation
* Easy installation and low cost
* Scalable for additional smart devices

## Hardware Components

* ESP32 Development Board
* 4-Channel 5V Relay Module
* Light Bulbs / Appliances
* Jumper Wires
* Power Supply

## Pin Connections

| Device  | ESP32 Pin |
| ------- | --------- |
| Relay 1 | GPIO 13   |
| Relay 2 | GPIO 12   |
| Relay 3 | GPIO 14   |
| Relay 4 | GPIO 27   |

## Software Used

* Arduino IDE
* Arduino IoT Cloud
* ESP32 Board Package

## Working Principle

The ESP32 connects to Wi-Fi and Arduino IoT Cloud. When a user toggles a switch from the cloud dashboard, the corresponding relay changes state and controls the connected appliance.
