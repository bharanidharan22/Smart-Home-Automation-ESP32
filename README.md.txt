# Smart Light Control System using ESP32

## Overview
This project controls a light using an ESP32 and a 5V relay module.

## Components Used
- ESP32 Development Board
- 5V Relay Module
- Light Bulb
- Power Supply
- Jumper Wires

## Circuit Connections

ESP32 GPIO 23 → Relay IN

ESP32 GND → Relay GND

5V Supply → Relay VCC

## Features
- Remote Light ON/OFF
- Low Cost Home Automation
- Easy to Expand
